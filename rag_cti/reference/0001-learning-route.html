Learning Route

Agentic RAG 工程学习路线

这条路线先给你全局地图，再进入局部概念。思维导图大约有 10 个分类、86 个概念节点；课程把它们折成 8 节课。每节课先讲概念位置，再用 CTI-RAG 代码或设计文档做辅助例子。

从 10 类概念到 8 节课

思维导图不是线性书本，而是一张工程地形图。课程顺序不按文件目录走，而按“你需要先有哪张概念坐标系”来走。

思维导图分类课程里的位置为什么这样放
输入理解与路由、Runtime/Harness、LLM 调用点、横切概念 第 1-3 课 先建立控制平面：任务如何进入系统、状态如何变化、工具如何被 runtime 约束。
检索与知识层、上下文与记忆 第 4 课 再建立证据平面：证据从长期知识源进入本次运行的 ledger 和 context。
证据约束与答案可信度 第 5 课 把 citation、grounding、faithfulness、sufficiency 拆开，避免把“有引用”误认为“可信”。
Multi-Agent / Supervisor 第 6 课 有了 state、ledger、grounding 以后，才容易理解 branch-local ledger、worker report、Composer。
Evaluation / Quality、Product/Ops 第 7-8 课 最后学习怎样分层评价、观察和审计整个系统，而不是只看一次答案。

课程顺序

课主题代码/文档入口你要学会评价什么
01 把 runtime harness 看成控制平面 answer(), RuntimeQueryUnderstanding, AdmissionResult 入口是否统一；路由是否保守；依赖与运行状态是否分离。
02 State 与 Observation：一次运行的控制记录 RuntimeInvestigationState, RuntimeObservation 每轮执行是否可解释；状态是否足够支持 stop policy 和 trace。
03 Tool Calling Boundary：把模型建议变成可审计行动 RuntimeTurnAdapter, _validate_runtime_tool_args(), agent_tools.py 工具名、参数、预算、deadline、重复调用、错误是否由代码约束。
04 Evidence Ledger：一次运行的证据权威 EvidenceLedger, retrieve_to_ledger(), graph_query_to_ledger() 模型看到的是摘要，系统保存的是完整结构化证据；哪些 ID 真正可引用。
05 Citation / Grounding / Faithfulness：把“有引用”拆成多个质量问题 assemble_citations(), build_agentic_answer(), SufficiencyVerdict 引用存在、claim 被支持、答案忠实、证据充分是不同问题。
06 Supervisor：Admission 之后的协调层 run_supervised_answer(), merge_branch_ledgers(), Composer supervisor 是否只协调；worker 是否只 gather；Composer 是否 no-tool synthesis。
07 Eval Harness：先说明你在测哪一层 retrieval_metrics.py, ragas_eval.py, eval scripts 每个指标测的是检索、收集证据、答案、faithfulness、citation、成本中的哪一层。
08 Architecture Review：从设计合同读到证据 ADR + runtime contract + tests + eval outputs 把设计意图、代码事实、测试证据、eval 证据和残余风险分开说清楚。

读代码顺序

先读设计边界

docs/adr/0001-runtime-harness-orchestration.md 定义 production runtime 的边界。先读它，再读代码。

再读入口代码

src/rag_cti/__init__.py 的 answer() 展示 runtime harness 如何选择 single-agent 或 supervisor。

再读运行时对象

runtime_harness.py 里的 query understanding、state、observation、tool validation 是第一阶段主菜。

最后读证据和质量

evidence_ledger.py、agentic_nodes.py、evaluation/ 负责证明答案从哪里来，以及质量如何被测。
