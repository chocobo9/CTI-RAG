## Factual bases

`non_otx_handoff/` is the strict five-file handoff for APTnotes, CIRCL MISP,
CISA, and ORKL. It contains 32,056 Events. Its current-reader and pipeline
results are in `non_otx_validation.json`.

`otx_handoff/part-00` through `part-03` contain the complete 17,454-Pulse OTX
factual base as 91 immutable shards. Every shard contains exactly:

- `events.jsonl`
- `nodes.jsonl`
- `edges.jsonl`
- `source_claims.jsonl`
- `rejected_records.jsonl`

The four parts contain 17,454 Events, 11,827,365 nodes, 28,099,223 edges,
547,528 claims, and 7,447,836 rejected records. `otx_handoff/shard_mapping.json`
preserves the original two-part build lineage and the deterministic four-part
assignment.

Run one shard from the EviTRAIL checkout:

```powershell
python -m evitrail.data.pipeline `
  --handoff <CTI-RAG>\rag_cti\data\evitrail_delivery_20260730\otx_handoff\part-00\shards\<shard> `
  --raw-root __disabled__ `
  --vocabulary <CTI-RAG>\rag_cti\data\evitrail_delivery_20260730\vocabulary\actor_vocabulary.json `
  --vocabulary-mode frozen `
  --enrichment none `
  --out <output>
```

## Frozen actor vocabulary

`vocabulary/` contains a 33-actor frozen vocabulary: the exact EviTRAIL
11-actor baseline plus 22 actors admitted from resolved factual attribution
claims. Admission requires at least five distinct Events and two distinct
factual sources. OTX tags and discovery matches are provenance-only and cannot
vote. MITRE ATT&CK and Malpedia are used only for identity and alias resolution.

The manifest contains 92 portable claim references: one non-OTX claims file
and all 91 final OTX shard claims files.
