# Ledger As Evidence Authority

The learner should understand EvidenceLedger as per-run evidence authority, not a list of tool returns.

Teaching preference:
- Distinguish corpus/graph/fact store, tool summary, ledger, prompt view, answer citations.
- Explain chunks, facts, outlines, and actions by their evidence role.
- Emphasize that prompt context is a projection; ledger is the structured authority.
- Multi-branch supervisor lessons must preserve branch-local ledger vs branch report.

Quality check:
- Exercises must ask which IDs are citable and why.
- Feedback must explain that action logs and outlines are useful but not claim proof.
