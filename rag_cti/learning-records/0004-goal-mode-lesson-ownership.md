# Goal Mode Lesson Ownership

When the user opens goal mode for the Agentic RAG course, the agent should own the learning outcome rather than merely generate lesson files.

Operational expectations:

- Start each lesson by recalibrating against `MISSION.md`, `NOTES.md`, learning records, the route page, and recent user feedback.
- Define one core conceptual win for the lesson before writing.
- Preserve the sequence: whole-map location, concept boundary, concrete scenario, common misconceptions, CTI-RAG code as supporting evidence, exercises, review links.
- Produce durable learning assets as needed: lesson HTML, reference page, glossary updates, route links, and learning records.
- Verify with the Lesson Quality Gate: TDD-style observable learning outcomes plus grill-with-docs teaching-quality questions.
- Report gate results and residual risks in the final response.

The agent should treat user corrections as curriculum design data and update the teaching workspace immediately.
