# Supervisor Coordination Not Brain

The learner was uncertain about supervisor positioning, so future lessons should keep concept and CTI-RAG implementation separate.

Teaching preference:
- Teach supervisor as coordination after runtime admission.
- Production path means validated branch plan; legacy autonomous supervisor is debug/eval/manual baseline.
- Supervisor dispatches gather-only workers, collects reports, merges ledgers, and triggers Composer.
- Supervisor should not route all queries, retrieve directly, write final answer, or validate citations.

Quality check:
- Exercises must include "when not to use supervisor."
- Feedback should explain independent gatherable branches vs dependent chains.
