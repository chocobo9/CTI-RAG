## Study Mode

The intended learning priority is concepts first, code second:

1. Locate the lesson in the whole Agentic RAG map.
2. Explain the core conceptual win in your own words.
3. Use the CTI-RAG code mapping as evidence, not as the starting point.
4. Work through the exercises and read the feedback carefully.
5. Ask the next session to quiz you on the conceptual boundaries before moving on.
