# Investigation Case and policy own investigator authority

CTI-RAG records each investigation in a persistent Investigation Case whose
Ledger is authoritative independently of the model transcript. Models may
propose semantic updates, actions, and Verdicts, but deterministic harness
policy owns action admission, permissions, budgets, lifecycle transitions,
continuation, abstention, and release; tools only execute admitted actions and
return Observations. This trades a simpler transcript-driven loop for durable
auditability, safe resume/replay, explicit uncertainty, and product-correct CTI
termination semantics.
