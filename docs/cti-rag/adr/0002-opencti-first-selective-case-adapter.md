# Use OpenCTI as the first selective Case source Adapter

The first production Case source Adapter targets OpenCTI but does not mirror its schema into Agent Investigation Workspace. Delivery begins with the distinct read-only `opencti-case-orientation/v1` Profile containing only qualified actor-scoped facts stock OpenCTI can prove. The later owned Case Management authority composes qualified OpenCTI observations with facade-owned revisioned semantic metadata to expose the complete `opencti-case-projection/v1`. This preserves a usable OpenCTI-first path without treating the source Adapter as Case business authority or Revision Authority.

## Consequences

Case-specific and global intelligence access remain separate logical ports even if both reuse one OpenCTI deployment. A direct OpenCTI Adapter is a qualified source for technical Case spine facts, Task-backed work, neutral object membership, and bounded change hints only after item-authorization, exhaustive traversal, version materialization, cursor recovery, and end-fence conformance are verified for the exact deployment.

The complete `opencti-case-projection/v1` additionally requires facade-owned revisioned purpose/mandate, scope/controls, classified Human Direction, accepted/negative findings, Case-role/evidence assessment, semantic change attribution, and proposal ledger metadata. Stock OpenCTI Notes, Opinions, statuses, labels, or containment cannot be promoted into those meanings. The stock-only Orientation therefore uses a different smaller Profile identity and cannot supply a write basis for the composed Profile.

Stock OpenCTI also does not supply the aggregate Case Revision, receiver-side conditional mutation, request-correlated idempotency/receipt, or conclusive status lookup required for strict writes. Those Capabilities remain disabled unless an owned Case Management facade supplies and qualifies those guarantees under the same Revision Authority as the Projection basis. Change streams and history invalidate or assist recovery; they are not authority proofs.
