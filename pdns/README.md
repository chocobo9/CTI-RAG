# EviTRAIL pDNS delivery

This archive contains the OTX and additional-sources Event datasets projected
with OTX passive DNS only. It preserves the frozen factual files and vocabulary;
it does not contain ASN nodes or `ip_in_asn` edges.

See the dataset manifests inside the archive and the branch-level
`ENRICHMENT_DELIVERY_SUMMARY.md` for counts and validation scope.
